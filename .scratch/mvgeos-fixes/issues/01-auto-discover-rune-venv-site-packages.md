# 01 — Auto-discover rune virtual environment site-packages in rune loader

**What to build:** Auto-discover and prepend `.venv` / `venv` site-packages for installed runes (e.g. `00-seeker`, `01-heal-my-goap`) when loading rune modules, ensuring external dependencies like `aiohttp` or custom local modules load cleanly without throwing `ModuleNotFoundError`.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `load_factory_from_manifest` in `mvgeos_runes/loader.py` inspects rune directories for `.venv/Lib/site-packages` (Windows) and `.venv/lib/python*/site-packages` (POSIX) and prepends them to `sys.path`.
- [ ] Installed runes with custom dependencies load successfully without raising `ModuleNotFoundError`.
- [ ] Load diagnostics explicitly mention declared missing `python_deps` when a rune module fails to load.
- [ ] Unit and integration tests in `mvgeos-runes/tests/` verify rune site-packages discovery.
